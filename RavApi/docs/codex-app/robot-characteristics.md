# Характеристики Роботів

## Як Читати Параметри

- Усі значення взято з поточного каталогу в `Data/SeedData.cs`; довідник охоплює всі 21 робот.
- `Точність` — розкид: **менше значення означає точнішу зброю**.
- Броня записана як `лоб / борт / тил`. Окремо наведено броню башти й корпусу.
- `Сер. DPS` — орієнтовна шкода за секунду без урахування промахів, броні та пробиття: середня шкода пострілу / перезаряджання.
- `Потужність двигуна` — окрема балансна характеристика в умовних одиницях; більше значення означає більший доступний запас потужності двигуна.
- Одиниці швидкості, прискорення, потужності двигуна, огляду та швидкості снаряда визначає ігровий клієнт; тут збережено точні значення API.
