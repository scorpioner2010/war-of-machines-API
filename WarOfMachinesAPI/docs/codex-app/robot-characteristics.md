# Характеристики Роботів

## Як Читати Параметри

- Усі значення взято з поточного каталогу в `Data/SeedData.cs`; довідник охоплює всі 8 роботів.
- `Точність` — розкид: **менше значення означає точнішу зброю**.
- Броня записана як `лоб / борт / тил`. Окремо наведено броню башти й корпусу.
- `Сер. DPS` — орієнтовна шкода за секунду без урахування промахів, броні та пробиття: середня шкода пострілу / перезаряджання.
- Одиниці швидкості, прискорення, огляду та швидкості снаряда визначає ігровий клієнт; тут збережено точні значення API.
